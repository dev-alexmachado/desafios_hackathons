## Python

### Django

#### Desafio QUA.544.003
---

Desenvolva um sistema de ***login*** do tipo **CRUD** (**C**reate, **R**ead, **U**pdate, **D**elete) com um tema à sua escolha. Ao terminar, crie um novo repositório público no GitHub e *commite* seu projeto nele.

- **Data de início**: 14/10/2026.
- **Data da entrega**: 20/10/2026.
- **Número mínimo de entidades**: 1.
- **Tema**: à sua escolha, menos o usado no último projeto.

> [!NOTE]
> **Obs:**
> - Pode ser em dupla, se assim desejar.
> - O projeto deve ser publicado em um novo repositório.
